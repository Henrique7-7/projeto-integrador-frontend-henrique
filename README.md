# Catalogo de Roupas Fitness
O Projeto tem como foco desenvolver um Catalogo de uma loja de roupas Fitness.
A pagina apresentara produtos como camisetas, shorts, leggings, tops e conjuntos esportivos.
O catalogo tera informacoes como nome, preco, categoria, descricao e imagens dos produtos.
O projeto sera desenvolvido durante a disciplina de Front-end.
## Créditos

- Fotos e vídeo: UpBella Moda Fitness, loja da minha família. O vídeo foi gravado com modelo contratada pela loja.
- Roupas da marca Sarados De Corpo e Alma, com autorização do dono da marca para uso nas publicações.
- Cores e fontes: manual de identidade visual da UpBella (NativusHub + Mavip).
- Fontes DM Sans e Oswald: Google Fonts, licença SIL Open Font License.
